Горохострел (Peashooter) — выдаётся сразу на старте (Уровень 1-1). Это ваше базовое атакующее растение, которое стреляет горошинами по одной линии.Подсолнух (Sunflower) — даётся после прохождения Уровня 1-1. Производит дополнительное солнце, необходимое для посадки других растений.Стеноорех (Wall-nut) — даётся после прохождения Уровня 1-2. Имеет большой запас здоровья и служит щитом, задерживая зомби.Вишнёвая бомба (Cherry Bomb) — дается после прохождения Уровня 1-3. Взрывается в зоне 3х3 клетки, мгновенно уничтожая большинство зомби.Стеblockол / Картофельная мина (Potato Mine) — даётся после прохождения Уровня 1-4. Взрывается, когда на неё наступает зомби, но ей нужно время, чтобы покрыться землёй и активироваться.
